# VIP CLEANING CENTER — уебсайт

Едностраничен сайт за автомивка VIP CLEANING CENTER, Стара Загора.
Чист HTML/CSS/JS без build стъпка: хоства се директно от GitHub Pages.

## Файлове

| Файл | Какво съдържа |
| --- | --- |
| `index.html` | Цялото съдържание: услуги, процес, ценоразпис (една програма), отзиви, въпроси, контакти |
| `styles.css` | Дизайн (цветовете са в `:root` най-отгоре) |
| `script.js` | Мобилно меню, анимации, карусел, „Отворено сега“, активна секция в менюто |
| `fonts/` | Шрифтовете Unbounded и Manrope (локално, без заявки към Google) |
| `images/` | Снимки в WebP + JPEG, в 3 размера за бързо зареждане на телефон |
| `404.html` | Страница „Не е намерена“ в стила на сайта |
| `sitemap.xml` | За Google Search Console |

Lighthouse (телефон): 98 скорост · 100 достъпност · 100 добри практики · 100 SEO.

## Преглед локално

Отворете `index.html` в браузъра или пуснете:

```bash
python3 -m http.server 8000
```

и отидете на http://localhost:8000.

## Публикуване (GitHub Pages)

Settings → Pages → Build and deployment → Source: **Deploy from a branch**,
Branch: **main**, папка **/ (root)** → Save.
След около минута сайтът е на `https://slavovayoana-cyber.github.io/vip-center/`.
Всеки push в `main` обновява сайта автоматично.

- [ ] Реални снимки от автомивката. Сега има временни безплатни снимки от Pexels
      ([кола](https://www.pexels.com/photo/cars-lights-car-vehicle-1729993/),
      [четка](https://www.pexels.com/photo/a-close-up-shot-of-a-person-brushing-a-car-6873020/)).
      Заменете файловете в `images/` със същите имена: `hero-{600,800,1100}` (4:5),
      `why-{600,800,1100}` (5:4), всеки като `.jpg` и `.webp`, и `og.jpg` (1200×630, за Facebook).
- [ ] Дали телефонът да остане в сайта. Ако не, бутоните „Обади се“ / „Запази час“ трябва да водят другаде
      (Viber, Facebook).
- [ ] Пране на салон: какво включва и цена (сега е „Цена по запитване“).
- [ ] Плащане с карта или само в брой (за раздел „Въпроси“).
- [ ] Потвърждение на рейтинга в Google (4.5 ★ / 64 отзива).
- [x] Ванът е на цената на джипа (28 €). Работното време е потвърдено.
- [ ] Цени: сега 25 € (лек автомобил) / 28 € (джип или ван). Клиентът каза, че по-късно може да станат 28 / 33 €
      (както е на табелото). Сменят се в ценоразписа, във „Въпроси“, в „Защо нас“ и в JSON-LD в `index.html`.
- [ ] Домейн (по желание), напр. `vipcleaning.bg`: Settings → Pages → Custom domain.
      След смяна на домейна обновете адреса в `canonical`, `og:url`, `og:image` и JSON-LD
      в `index.html`, в `sitemap.xml` и пътищата `/vip-center/` в `404.html`.
